# AI Sales Coach — Interactive Demo

Self-contained demo site for **AI Sales Coach** (AI 营销陪练), a role-play trainer for sales teams.

- `index.html` — language picker
- `demo-en.html` — English demo (~3 min, fully offline, built-in scripted session)
- `demo.html` — 中文演示

No backend, no build step required — pure static files (relative paths), deployable to any static host.

Built from the `lms` frontend (`frontend/vite.demo.config.ts`).
